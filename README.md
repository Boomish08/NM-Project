# Simple Calculator

A basic calculator web app built with **HTML, CSS and JavaScript**. It runs directly in the browser and can be hosted for free on **GitHub Pages**.

## Features
- Addition, subtraction, multiplication and division
- Percentage, backspace and clear (AC)
- Decimal numbers
- Divide-by-zero error handling
- Keyboard support (0-9, + - * /, Enter, Backspace, Esc)
- Responsive design for mobile and desktop

## Project Structure
```
├── index.html   # Page structure
├── style.css    # Styling
├── script.js    # Calculator logic
└── README.md
```

## Run Locally
Download or clone the repository and open `index.html` in any browser. No installation needed.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (for example `calculator`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
5. After a minute, your site is live at `https://<your-username>.github.io/calculator/`.
